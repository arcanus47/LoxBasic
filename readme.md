# LoxBasic

## Lenguaje de programación educativo para aprender programación real

---

# 1. Visión del proyecto

**LoxBasic** es un lenguaje de programación diseñado para enseñar programación de forma clara, progresiva y práctica.

El proyecto nace de una idea sencilla:

> **Una persona que está aprendiendo a programar no debería tener que enfrentarse desde el primer día a toda la complejidad de un lenguaje profesional.**

LoxBasic busca proporcionar un punto de entrada intermedio entre el pseudocódigo y los lenguajes de programación profesionales.

El estudiante no solamente escribirá algoritmos o pseudocódigo.

**Escribirá programas reales utilizando un lenguaje de programación interpretable y ejecutable.**

La finalidad de LoxBasic no es que el estudiante permanezca necesariamente en LoxBasic para siempre, sino que adquiera una base sólida de programación que posteriormente pueda transferir a lenguajes como Python, Java, C#, C++, JavaScript, Go u otros.

---

# 2. Problema que busca resolver

Muchas personas que quieren aprender programación se encuentran con una dificultad inicial:

```text
Quiero aprender programación
        ↓
Necesito aprender un lenguaje
        ↓
El lenguaje tiene mucha sintaxis y conceptos nuevos
        ↓
Me cuesta entender qué está pasando
        ↓
Termino concentrándome en la sintaxis
        ↓
Pierdo de vista la lógica de programación
```

Por otro lado, las herramientas basadas en pseudocódigo permiten comenzar con mayor facilidad, pero existe una separación posterior entre:

```text
Pseudocódigo
     ↓
Aprender lógica
     ↓
Lenguaje de programación real
```

LoxBasic busca reducir esa separación.

La idea es:

```text
Conceptos fundamentales
        ↓
LoxBasic
        ↓
Programación real
        ↓
Lenguajes profesionales
```

---

# 3. Qué es LoxBasic

LoxBasic es:

* Un lenguaje de programación real.
* Un lenguaje interpretado.
* Un lenguaje de sintaxis sencilla.
* Un lenguaje orientado al aprendizaje.
* Un lenguaje pensado principalmente para principiantes.
* Un entorno para aprender los fundamentos de programación.
* Una herramienta para crear programas ejecutables.
* Un puente conceptual hacia otros lenguajes.

LoxBasic NO pretende ser:

* Un lenguaje profesional de propósito general.
* Un reemplazo de Python, Java, C#, C++, etc.
* Una herramienta exclusivamente para niños.
* Un sistema de pseudocódigo.
* Una plataforma limitada únicamente a algoritmos escritos en papel.
* Un lenguaje diseñado para competir por cantidad de funcionalidades con lenguajes profesionales.

# 5. Enfoque educativo

LoxBasic estará orientado principalmente a personas jóvenes y adultas.

No se diseñará como una herramienta infantil.

Esto significa que:

* La interfaz será moderna.
* El lenguaje será sencillo, pero no infantilizado.
* Los ejemplos tratarán problemas reales.
* Los ejercicios estarán orientados a desarrollar lógica.
* La documentación utilizará explicaciones técnicas pero comprensibles.
* El estudiante podrá crear programas reales.
* El entorno podrá utilizarse tanto de manera autodidacta como académica.

La filosofía será:

> **Simplificar la programación, no ocultarla.**

El estudiante no necesita conocer toda la complejidad de un lenguaje profesional desde el principio, pero sí debe comprender qué está haciendo.

# 8. LoxBasic como puente hacia otros lenguajes

Una de las características fundamentales del proyecto será enseñar conceptos que puedan transferirse fácilmente a otros lenguajes.

Por ejemplo:

```text
LOXBASIC                         PYTHON

LET nombre = "Ana"              nombre = "Ana"

IF edad >= 18 THEN               if edad >= 18:

FOR i = 1 TO 10                  for i in range(1, 11):

PRINT nombre                     print(nombre)
```

La intención no es que el estudiante memorice únicamente la sintaxis de LoxBasic.

La intención es que comprenda:

```text
variable
condición
repetición
función
colección
expresión
algoritmo
```

Posteriormente podrá aprender cómo esos mismos conceptos se expresan en otros lenguajes.

# 9. Relación con el pseudocódigo

LoxBasic no pretende ser simplemente otra herramienta de pseudocódigo.

El estudiante puede aprender inicialmente conceptos algorítmicos utilizando pseudocódigo, pero LoxBasic introduce un siguiente nivel:

```text
Pseudocódigo
     ↓
Comprender la lógica
     ↓
LoxBasic
     ↓
Escribir programas reales
     ↓
Python / Java / C# / C++ / JavaScript / etc.
```

La diferencia fundamental es que LoxBasic es un lenguaje de programación ejecutable.

El estudiante puede escribir:

```text
LET total = 0

FOR i = 1 TO 10
    LET total = total + i
NEXT

PRINT total
```

y obtener un resultado real.

# 10. Filosofía de diseño

LoxBasic seguirá una serie de principios fundamentales.

## 10.1 Simplicidad

La sintaxis debe ser fácil de leer y aprender.

## 10.2 Programación real

El estudiante debe escribir programas ejecutables.

## 10.3 Educación

Cada característica debe tener una razón educativa clara.

## 10.4 Transferibilidad

Los conceptos aprendidos deben ser útiles posteriormente en otros lenguajes.

## 10.5 Transparencia

El estudiante debe poder entender qué está haciendo el intérprete.

## 10.6 Progresividad

La complejidad debe aparecer gradualmente.

## 10.7 Modernidad

El lenguaje puede ser sencillo sin que el proyecto tenga una apariencia o infraestructura anticuada.

## 10.8 No infantilización

El público principal son jóvenes, universitarios, adultos principiantes y autodidactas.

## 10.9 Estabilidad

Las nuevas características no deben introducirse sacrificando la estabilidad del lenguaje.

# 11. Una característica diferencial: modo educativo

LoxBasic ya tuvo históricamente la idea de disponer de un modo en el que el intérprete explica cómo procesa las instrucciones.

Esta característica será estudiada y potencialmente convertida en uno de los pilares del nuevo proyecto.

Ejemplo:

```text
LET x = 10
```

En ejecución normal:

```text
```

En modo educativo:

```text
INSTRUCCIÓN

LET x = 10

→ Se encontró la palabra reservada LET.
→ Se encontró el identificador x.
→ Se evaluó el valor 10.
→ Se creó la variable x.
→ x = 10
```

Otro ejemplo:

```text
PRINT x + y
```

El entorno podría mostrar:

```text
ANALIZANDO EXPRESIÓN

x = 10
y = 20

10 + 20

Resultado:
30

→ Se imprime 30
```

El objetivo es que el estudiante pueda comprender no solamente:

> "qué resultado produjo mi programa"

sino:

> "qué hizo el lenguaje para producir ese resultado".

# 12. Sistema de errores educativos

Los errores también deberán formar parte de la experiencia educativa.

En lugar de mostrar únicamente errores técnicos difíciles de interpretar:

```text
SyntaxError
```

LoxBasic buscará proporcionar mensajes más comprensibles.

Ejemplo:

```text
ERROR EN LA LÍNEA 8

Encontramos:

IF edad >= 18

La instrucción IF necesita THEN.

Probablemente quisiste escribir:

IF edad >= 18 THEN
```

Cuando sea apropiado, el sistema podrá explicar también el concepto relacionado con el error.

Esto permitirá que el estudiante aprenda mientras corrige sus programas.

El proyecto existente debe ser auditado antes de decidir qué reemplazar.

# 30. Transferencia hacia Python

Por ejemplo:

```text
LOXBASIC

LET total = 0

FOR i = 1 TO 10
    LET total = total + i
NEXT

PRINT total
```

Posteriormente:

```text
PYTHON

total = 0

for i in range(1, 11):
    total = total + i

print(total)
```

El estudiante debe reconocer que:

```text
el lenguaje cambió
```

pero:

```text
la lógica no.
```

Ese será uno de los objetivos educativos fundamentales.


El lenguaje debe ser sencillo sin ser infantil, educativo sin ocultar la programación y accesible sin renunciar a conceptos reales.

El proyecto parte de un lenguaje desarrollado originalmente en 2020 por Cheremi Checo Domínguez.

La nueva generación, **LoxBasic 2.0**, no comenzará desde cero. Primero se realizará una auditoría del proyecto original, posteriormente se estabilizará y documentará el lenguaje, se desarrollará un entorno moderno y finalmente se construirá una experiencia educativa completa.

El objetivo final es que un estudiante pueda comenzar diciendo:

> "Nunca he programado."

y progresivamente llegar a:

> "Ya entiendo cómo funcionan las variables, las condiciones, los ciclos, las funciones, las colecciones y los algoritmos, y ahora puedo continuar aprendiendo Python, Java, C#, C++ u otro lenguaje profesional."
